🚀 کتابخانه‌های تک‌فایلی آماده (Single-File Client Libraries)

این کتابخانه‌ها کاملاً مستقل (Zero-Dependency) طراحی شده‌اند و می‌توانید فایل منفرد مربوط به زبان خود را بدون هیچ وابستگی جانبی مستقیماً در پروژه‌تان اضافه کنید:

// 1. Import or include lib/iranian-banks.js const { detect, isValidCard, isValidSheba, detectCard } = require('./lib/iranian-banks.js'); // Autodetect Card or SHEBA const res = detect('5022291234567890'); console.log(res.bank.name_fa); // "ویپاد (ترابانک پاسارگاد)" console.log(res.bank.color); // "#0E7490" console.log(res.valid); // true/false (Luhn algorithm)
# 1. Import lib/iranian-banks.py import iranian_banks as ib # Autodetect Card or SHEBA res = ib.detect('6219861812345678') print(res['bank']['name_fa']) # 'بلوبانک (نئوبانک سامان)' print(res['valid']) # True/False
<?php require_once __DIR__ . '/lib/iranian-banks.php'; use MehrNet\IranianBanks; // Autodetect Card or SHEBA $res = IranianBanks::detect('5022-2912-3456-7890'); echo $res['bank']['name_fa']; // "ویپاد (ترابانک پاسارگاد)" echo $res['valid'] ? 'معتبر' : 'نامعتبر';

پروژه متن‌باز و آزاد تحت پروانه MIT — طراحی و نگهداری توسط MehrNet
